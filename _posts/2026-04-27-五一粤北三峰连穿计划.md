## 📋 详细行程表

### Day 1 — 5月1日（周四）广州→罗坑大草原

| 时间 | 事项 | 备注 |
|:---:|:---|:---|
| 08:00 | 🚗 广州出发 | 导航"韶关曲江区罗坑镇"，预计车程3h |
| 11:00 | 🛒 罗坑镇补给采购 | 买水、食材、零食、烧烤物资 |
| 11:30 | 🍜 罗坑镇午餐 | 推荐：镇上河鲜/农家菜 |
| 13:00 | 🏕️ 抵达罗坑大草原 | 找好营地，搭天幕 |
| 13:30-18:00 | 🎣 自由活动 | 草原散步、拍照、钓鱼、发呆 |
| 18:00-20:00 | 🔥 晚餐/烧烤 | 自带烧烤食材+租炉具 |
| 20:00-22:00 | 🌌 星空聊天 | 大草原光污染少，天气好可见银河 |
| 22:00 | 😴 露营休息 | **无装备怎么办？往下看⬇️** |

> **⚠️ 关于无装备露营：**
> - 罗坑镇有**户外装备租赁**（帐篷+睡袋+防潮垫，约60-80元/套）
> - 也可以联系当地农家乐（如**罗坑生态农庄**），他们有帐篷出租，甚至提供营地+帐篷套餐
> - 建议提前联系预订：罗坑大草原附近的民宿老板基本都有露营装备可以租，或者直接住他们的帐篷位
> - **Plan B**：如果实在租不到，罗坑镇上有旅馆/民宿可以住，第二天一早5点出发赶狗尾嶂也行

### Day 2 — 5月2日（周五）狗尾嶂→郴州

| 时间 | 事项 | 备注 |
|:---:|:---|:---|
| 05:30 | ⏰ 起床收营 | 摸黑收帐篷，吃简单早餐 |
| 06:00 | 🚗 出发前往狗尾嶂 | 导航"狗尾嶂"，罗坑→狗尾嶂约40km，车程50min |
| 06:50 | 🅿️ 抵达登山口 | 停车，整理装备，热身 |
| 07:00 | 🥾 **开始登山** | 狗尾嶂海拔约1680m，爬升约900m |
| 09:30 | ⛰️ **登顶狗尾嶂** | 预计耗时2.5h登顶，山顶拍照、休息 |
| 10:00 | 🏃 **开始下山** | 原路返回或环线 |
| 11:30 | 🚗 回到车上 | 全程约4.5h（含休息） |
| 12:00 | 🍜 乳源县城午餐 | 推荐：乳源猪脚粉/本地特色菜 |
| 13:00 | 🚗 出发去郴州 | 乳源→郴州约180km，车程2.5h |
| 15:30 | 🏙️ 抵达郴州市区 | 自由时间 |
| 16:00-18:00 | 🚶 郴州闲逛 | 北湖公园/五岭广场/裕后街 |
| 18:00 | 🍜 晚餐 | 推荐：郴州鱼粉、血鸭、烧鸡公 |
| 20:00 | ♨️ **水疗水会过夜** | 找一家带过夜的水疗/水会（如**郴州悦海温泉**或当地水疗会所） |
| 一整晚 | 😴 水疗过夜 | 泡澡+汗蒸+休息大厅过夜，划算又舒服 |

> **关于水疗水会：**
> - 郴州比较推荐的水疗有：**悦海温泉酒店**、**郴州国际温泉城**等
> - 一般团购价80-150元/人，含温泉/水疗+休息大厅过夜
> - 部分还含自助餐，具体看套餐
> - 某团/某点评搜索"郴州水疗过夜"即可

### Day 3 — 5月3日（周六）郴州→狮子口夜爬

| 时间 | 事项 | 备注 |
|:---:|:---|:---|
| 08:00-12:00 | 😴 睡到自然醒 | 水会过夜的舒服之处 |
| 12:00 | 🥟 午餐 | 郴州市区吃顿好的 |
| 13:00-15:00 | 🚶 自由时间 | 可以逛逛郴州博物馆或裕后街 |
| 15:00 | 🚗 出发去狮子口 | 导航"狮子口"，郴州→狮子口约80km，车程1.5h |
| 16:30 | 🅿️ 抵达狮子口登山口 | 整理装备，分装夜爬物资 |
| 17:00-20:00 | 🌄 山下休整/晚餐 | 提前吃点东西，检查头灯/备用电池 |
| 20:00 | 🌙 **开始夜爬狮子口** | 狮子口海拔约1956m，爬升约1100m |
| 23:30 | ⛰️ **登顶狮子口** | 预计耗时3.5h夜爬登顶 |
| 23:30-02:00 | 🌌 山顶休息/看星空 | 夜爬的好处：山顶没人，星空绝佳 |
| 02:00 | 💤 **山顶扎营休息** | 轻量化露营（如果带了装备）或直接在山顶避风处休息等日出 |

> **关于夜爬狮子口的准备：**
> - **头灯/手电**必带！至少两套电池
> - 山顶风大温差大，带**冲锋衣/羽绒服**
> - 备足饮水（至少2L）
> - 狮子口路线较成熟，但夜间需注意路标
> - **建议结伴而行**，夜爬有一定风险

## 🎒 装备清单

### 必备装备
- 🥾 登山鞋/越野跑鞋
- 🧥 冲锋衣/防风外套（山顶温差大）
- 🔦 头灯+备用电池（夜爬必备！）
- 🧴 防晒霜、帽子
- 💧 水袋/水瓶（每天至少2L）
- 🍫 路餐（能量棒、巧克力、坚果）
- 📱 充电宝
- 🆔 身份证（水疗过夜需要）

### 建议携带
- 🏕️ 轻量化帐篷+睡袋（如果想在狮子口山顶露营等日出）
- 🧦 换洗衣物（水疗后可以洗澡换衣）
- 🎒 登山杖（狗尾嶂和狮子口都建议）
- 🧊 急救包
- 🗺️ 离线地图（部分路段信号差）

## ⚠️ 注意事项

1. **天气**：五一期间粤北多雨，务必关注天气预报，备好雨衣
2. **体力**：连续三天高强度运动，量力而行
3. **安全**：夜爬一定要组队，不要单独行动
4. **露营装备**：罗坑租装备记得提前联系确认
5. **狗尾嶂难度**：中等，部分路段较陡，建议用登山杖
6. **狮子口夜爬**：全程约8km，爬升1100m，需4-5h
7. **交通**：全程自驾，建议至少2人轮流开车，安全第一
