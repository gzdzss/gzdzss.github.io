## 📌 什么是大朝台？

五台山大朝台，即徒步登上五台山的**五个台顶**（东台望海峰、北台叶斗峰、中台翠岩峰、西台挂月峰、南台锦绣峰），分别供奉着文殊菩萨的五种智慧身。

**顺朝**（顺时针大朝台）：鸿门岩 → 东台 → 鸿门岩 → 北台 → 中台 → 西台 → 狮子窝 → 南台 → 佛母洞 → 白云寺。

全程约 **55-60公里**，累计爬升约 **1800米**。3天2夜是性价比最高的节奏 —— 不太赶，也不太慢，能好好感受五台山的高山草甸和寺院文化。体能好的老驴可以压缩到2天，但那基本就是赶路了。

## ✈️ 大交通：广州 → 忻州五台山

### 推荐方案：直飞忻州五台山机场

| 项目 | 详情 |
|:---|:---|
| **航线** | 广州白云(CAN) → 忻州五台山机场(WUT) |
| **飞行时间** | 约 **3小时** |
| **参考航班** | 南方航空 CZ6623 等（每天1-2班） |
| **机场 → 景区** | 乘坐机场大巴到五台山景区（约2.5h，**60元左右**）→ 再打车到鸿门岩/东台 |

> 💡 五台山机场较小，航班不多，**建议提前订票**。旺季（6-8月）会有加密航班。

### 备选方案：经太原中转

| 项目 | 详情 |
|:---|:---|
| **航线** | 广州白云 → 太原武宿机场（航班更多，票价通常更便宜） |
| **太原 → 五台山** | 太原客运东站乘大巴到五台山（约3.5h，**145元**） |

## 🗓️ 详细行程

### Day 1：鸿门岩 → 东台 → 北台 → 澡浴池
**路程**：约15km | **累计爬升**：约1000m | **用时**：7-8h

| 时间 | 内容 |
|:---|:---|
| 06:30-07:00 | 五台山景区出发，打车到**鸿门岩**（朝台起点） |
| 07:00-08:30 | 🏔️ **鸿门岩 → 东台望海峰**（1.5-2h）<br>想看日出？5点前出发！ |
| 08:30-09:00 | 东台休息、吃早餐、拍照打卡 📸 |
| 09:00-13:00 | 🔥 **东台 → 北台叶斗峰**（3.5-4h）<br>海拔3061m，**华北屋脊**！这段是最虐的，全程大爬升 |
| 13:00-14:00 | 北台午餐路餐，补充体力 |
| 14:00-16:30 | **北台 → 澡浴池**（2-2.5h），途经中台 |
| 16:30 | 🏠 **住宿**：澡浴池寺挂单 |

> **住宿说明**：澡浴池寺挂单，床位约**50-80元/人**含早晚餐。条件简单（通铺/多人间），但热饭热菜管饱，在山上这就很幸福了。

---

### Day 2：澡浴池 → 中台 → 西台 → 狮子窝 → 吉祥寺
**路程**：约18km | **累计爬升**：约600m | **用时**：7-8h

| 时间 | 内容 |
|:---|:---|
| 07:00-08:00 | 寺里吃早斋后出发 |
| 08:00-09:30 | 🏔️ **澡浴池 → 中台翠岩峰**（1.5h） |
| 09:30-12:00 | 🌿 **中台 → 西台挂月峰**（2.5h）<br>这段有漂亮的高山草甸，是全程风景最好的路段之一 |
| 12:00-13:00 | 西台午餐路餐 |
| 13:00-16:30 | **西台 → 狮子窝 → 吉祥寺**（3.5-4h） |
| 16:30 | 🏠 **住宿**：狮子窝或吉祥寺挂单 |

> **住宿说明**：狮子窝最有名，挂单的人也最多。吉祥寺相对安静一些。条件都和澡浴池差不多。

---

### Day 3：吉祥寺 → 南台 → 佛母洞 → 白云寺
**路程**：约22km | **累计爬升**：约600m | **用时**：7-8h

| 时间 | 内容 |
|:---|:---|
| 06:30-07:00 | 早斋后出发 |
| 07:00-11:30 | 🔥 **吉祥寺 → 南台锦绣峰**（4-4.5h）<br>最后一座台！这段路程最长，需要留足体力 |
| 11:30-12:30 | 南台午餐，休息，和台顶的文殊菩萨告别 🙏 |
| 12:30-14:30 | 🏔️ **南台 → 佛母洞**（2h）<br>经典下山路线，风景优美 |
| 14:30-15:30 | **佛母洞 → 白云寺**（1h），出山！🎉 |
| 15:30之后 | 白云寺打车回台怀镇，或直接前往五台山机场返程 |

> ⚠️ **赶飞机注意**：如果当天要飞回广州，建议订 **18:00以后** 的航班，留足充裕时间。

## 🎒 装备清单

### ✅ 必备装备

| 装备 | 说明 |
|:---|:---|
| 🥾 **登山鞋** | 防滑防水最佳，石子路和泥路很多 |
| 🧥 **冲锋衣/软壳** | 山顶风大，夏天也可能只有 **5-10°C** |
| 👕 **速干衣裤** + 保暖层 | 抓绒或轻薄羽绒服，早晚温差巨大 |
| 🦯 **登山杖** | **两根最好**，省力30%+，下坡保护膝盖 |
| 🎒 **背包** | 30-40L足够 |
| 🔦 **头灯** | Day 1可能走到傍晚 |
| 💧 **水壶** | 至少1.5L，路上寺庙可补水 |
| 🍫 **路餐** | 巧克力、能量棒、牛肉干、面包等 |

### ✅ 建议携带

| 装备 | 说明 |
|:---|:---|
| 🌞 防晒霜 + 🕶️ 墨镜 | 高海拔紫外线强烈，别小看 |
| ☂️ 雨衣/雨罩 | 山里天气说变就变，上午晴天下午暴雨不奇怪 |
| 🔋 充电宝 | 寺庙充电不便 |
| 💵 零钱现金 | 挂单费、香火钱，山上信号差移动支付不好使 |
| 🦵 护膝 | 三天加起来下坡不少，护膝能救命 |
| 🧭 离线轨迹 | 提前下载**两步路/六只脚**的顺朝轨迹，山上信号时有时无 |

| 季节 | 评价 |

## ⚠️ 重要提示

1. **🏠 提前挂单预约**：旺季（7-10月）建议提前打电话问寺庙床位，否则可能没地方住
2. **💪 评估体力**：顺朝每天15-22km，累计爬升不小，建议有徒步基础再走
3. **📍 离线导航**：山上信号**时好时坏**，提前下载好离线轨迹
4. **🌱 环保**：请把垃圾带下山，台顶生态非常脆弱
5. **⛈️ 安全第一**：台顶天气**突变极快**，遇大风大雨果断下撤或原地避险
6. **🔄 逆朝（反穿）**：如果觉得顺朝太累，可考虑**逆朝**（南台→西台→中台→北台→东台），第一天爬升更缓，适合入门
