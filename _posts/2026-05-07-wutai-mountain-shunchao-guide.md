## 📌 什么是大朝台？

五台山大朝台，即徒步登上五台山的**五个台顶**（东台望海峰、北台叶斗峰、中台翠岩峰、西台挂月峰、南台锦绣峰），分别供奉着文殊菩萨的五种智慧身。

**顺朝**（顺时针大朝台）：鸿门岩 → 东台 → 南台 → 西台 → 中台 → 北台 → 鸿门岩。

本文提供两种路线选择：

| 路线 | 里程 | 累计爬升/下降 | 天数 | 强度 |
|:---:|:---:|:---:|:---:|:---:|
| **经典顺朝** | 55-60km | 1800m | 3天 | ⭐⭐⭐ |
| **大环顺朝** | 72km | 3600m↑ / 3600m↓ | 4天 | ⭐⭐⭐⭐⭐ |

> ⚠️ **大环顺朝第一天强度较高**，雨雪天气路线较为难走，总爬升下降各3600米，请结合自身情况量力而行。

## ✈️ 大交通：广州 → 五台山

### 方案一：直飞忻州五台山机场

| 项目 | 详情 |
|:---|:---|
| **航线** | 广州白云(CAN) → 忻州五台山机场(WUT) |
| **飞行时间** | 约 **3小时** |
| **参考航班** | 南方航空 CZ6623 等（每天1-2班） |
| **机场 → 景区** | 机场大巴到五台山景区（约2.5h，**60元左右**）→ 打车到鸿门岩/东台 |

> 💡 五台山机场较小，航班不多，**建议提前订票**。旺季（6-8月）会有加密航班。

### 方案二：经太原中转（航班更多、票价更低）

| 项目 | 详情 |
|:---|:---|
| **航线** | 广州白云 → 太原武宿机场 |
| **太原 → 砂河** | 太原客运东站 → 砂河站（**59元**，8:10-18:00，班次间隔1-2h，车程约4h） |
| **砂河 → 鸿门岩** | 拼车 **30元** / 包车 **100元** |

> 💡 太原出发更灵活，航班选择多，适合不赶时间的行程。

## 🗓️ 详细行程

### 🌟 方案一：大环顺朝（72km · 4天）

> 适合有一定徒步经验的户外爱好者，风景更丰富，体验更完整。

#### Day 0：广州 → 太原

| 项目 | 详情 |
|:---|:---|
| **交通** | 广州白云 → 太原武宿机场（航班多，票价低） |
| **住宿** | 太原市区酒店（推荐太原东站附近，方便第二天赶车） |

#### Day 1：太原 → 砂河 → 鸿门岩 → 东台

| 段落 | 交通方式 | 费用 | 备注 |
|:---|:---|:---|:---|
| 太原东站 → 砂河站 | 大巴 | **59元** | 8:10-18:00发车，班次间隔1-2h，车程约4h |
| 砂河 → 鸿门岩 | 拼车/包车 | **30/100元** | 出发点 |
| 鸿门岩 → 东台 | 徒步 ⬆️250m | - | 约1.5-2h，想看日出需次日早起 |

**住宿**：东台挂单 **100元**（包早晚餐），早餐5-7点，晚餐6:30-8:30，有开水、无洗浴、无补给、有卫生间🚻，盖章10元

#### Day 2：东台 → 护银沟 → 宽滩村 → 南台 → 大南庄

| 段落 | 爬升/下降 | 备注 |
|:---|:---|:---|
| 东台 → 护银沟 | ⬆️600m / ⬇️1600m | **风景最美路段**，雨雪天特难走 |
| 护银沟（2-4km处） | - | 唯一能吃到肉的地方，平价 |
| 护银沟 → 宽滩村 | 多缓坡 | 补给2倍，可坐车20元到大南庄 |
| 宽滩村 → 南台 | ⬆️800m | 盖章10元 |
| 南台 → 大南庄 | - | 可坐车60元 |

**住宿**：大南庄挂单 **100元**（包早晚餐），可洗浴，补给1-1.5倍，有卫生间🚻

> ⚠️ **警告**：东台到护银沟只有一个补给点，价格2.5倍，务必备好物资！

#### Day 3：大南庄 → 狮子窝 → 吉祥寺 → 西台 → 中台 → 澡浴池

| 段落 | 爬升/下降 | 备注 |
|:---|:---|:---|
| 大南庄 → 金阁寺（1km） | - | 补给2倍，可坐车80元到吉祥寺 |
| 金阁寺 → 狮子窝 | - | 补给2.5倍，有卫生间🚻 |
| 狮子窝 → 吉祥寺 | - | 补给2.5倍，有卫生间🚻，盖章50元 |
| 吉祥寺 → 西台 | ⬆️450m | 盖章10元，有卫生间🚻 |
| 西台 → 中台 | ⬆️380m | 盖章10元，补给2.5倍，有卫生间🚻 |
| 中台 → 澡浴池 | ⬇️200m | - |

**住宿**：澡浴池挂单 **100元**（包早晚餐，斋饭），早餐6点开始，可洗澡，有卫生间🚻，补给2倍

> 💡 澡浴池床位紧张，**务必早到**，否则只能睡走廊或打地铺！

#### Day 4：澡浴池 → 北台 → 鸿门岩 → 返程

| 段落 | 爬升/下降 | 备注 |
|:---|:---|:---|
| 澡浴池 → 北台 | ⬆️300m | 华北屋脊3061m，盖章10元，补给2.5倍，有卫生间🚻 |
| 北台 → 鸿门岩 | ⬆️400m / ⬇️700m | 终点！ |

**返程**：
| 段落 | 交通方式 | 费用 | 备注 |
|:---|:---|:---|:---|
| 鸿门岩 → 砂河 | 拼车/包车 | **30/100元** | - |
| 砂河 → 太原东站 | 大巴 | **50元** | 5:00-16:30发车，班次间隔1-2h |
| 太原 → 广州 | 飞机 | - | 建议订 **20:00以后** 的航班 |

### 方案二：经典顺朝（55-60km · 3天）

> 适合时间有限、想体验朝台但不追求极致的徒步者。

#### Day 1：鸿门岩 → 东台 → 北台 → 澡浴池

| 段落 | 爬升/下降 | 用时 | 备注 |
|:---|:---|:---|:---|
| 鸿门岩 → 东台 | ⬆️ 250m | 1.5-2h | 想看日出需5点前出发 |
| 东台 → 北台 | ⬆️ 约1000m | 3.5-4h | **最虐路段**，海拔3061m华北屋脊 |
| 北台 → 澡浴池 | ⬇️ 200m，途经中台 | 2-2.5h | |

**住宿**：澡浴池挂单 **100元**（包早晚餐），早餐6点开始，需早到否则睡走廊/打地铺，可洗澡

#### Day 2：澡浴池 → 中台 → 西台 → 狮子窝 → 吉祥寺

| 段落 | 爬升/下降 | 用时 | 备注 |
|:---|:---|:---|:---|
| 澡浴池 → 中台 | ⬆️ 380m | 1.5h | 盖章10元 |
| 中台 → 西台 | ⬆️ 450m | 2.5h | 高山草甸，风景最好路段之一 |
| 西台 → 狮子窝 → 吉祥寺 | - | 3.5-4h | 吉祥寺盖章50元 |

**住宿**：狮子窝或吉祥寺挂单

#### Day 3：吉祥寺 → 南台 → 佛母洞 → 白云寺

| 段落 | 爬升/下降 | 用时 | 备注 |
|:---|:---|:---|:---|
| 吉祥寺 → 南台 | ⬆️ 800m | 4-4.5h | **路程最长**，需留足体力 |
| 南台 → 佛母洞 | ⬇️ - | 2h | 经典下山路线，风景优美 |
| 佛母洞 → 白云寺 | - | 1h | 出山！ |

> ⚠️ **赶飞机注意**：如果当天要飞回广州，建议订 **18:00以后** 的航班，留足充裕时间。

## 🎒 装备清单

### ✅ 必备装备

| 装备 | 说明 |
|:---|:---|
| 🥾 **登山鞋** | 防滑防水最佳，石子路和泥路很多 |
| 🧥 **冲锋衣/软壳** | 山顶风大，夏天也可能只有 **5-10°C** |
| 👕 **速干衣裤** + 保暖层 | 抓绒或轻薄羽绒服，早晚温差巨大 |
| 🦯 **登山杖** | **两根最好**，省力30%+，下坡保护膝盖 |
| 🎒 **背包** | 30-40L足够 |
| 🔦 **头灯** | 可能走到傍晚，不走夜路 |
| 💧 **水壶** | 至少1.5L，路上寺庙可补水 |
| 🍫 **路餐** | 巧克力、能量棒、牛肉干、面包等 |

### ✅ 强烈建议

| 装备 | 说明 |
|:---|:---|
| 🦵 **护膝** | 下坡较陡，护膝能救命 |
| ☂️ **雨衣** | 山里天气说变就变，上午晴天下午暴雨不奇怪 |
| 🧴 **电解质/盐丸** | 高强度运动必备 |
| 🌞 **防晒套装**（防晒霜+墨镜） | 高海拔紫外线极强 |
| 🍬 **糖分高的食品** | 快速补充能量 |
| 🔇 **耳塞** | 寺院多人间，睡眠质量重要 |
| 🦟 **驱蚊液** | 夏季必备 |
| 🏥 **急救包** | 常用药、创可贴等 |
| 🧭 **离线轨迹** | 提前下载**两步路/六只脚**轨迹 |
| 💵 **现金** | 山上信号差，移动支付不好使 |

## ⚠️ 重要提示

### 寺院规矩
- 🈲 **荤腥**：寺院禁止荤食
- 🈲 **喧哗**：保持安静
- 🈲 **浪费粮食**：斋饭要吃完
- 🈲 **拍照**：殿堂内禁止拍照
- 🈲 **与护法神合影**

### 安全须知
1. **早睡早起不走夜路**：山上路况复杂，夜间行走风险大
2. **提前挂单预约**：旺季（7-10月）建议提前打电话问寺庙床位
3. **评估体力**：顺朝55-60km，建议有徒步基础
4. **离线导航**：山上信号**时好时坏**，提前下载离线轨迹
5. **准备移动卡**：很多地方只有移动有信号
6. **准备现金**：山上信号差，移动支付不好使
7. **环保出行**：垃圾随身带走，台顶生态脆弱
8. **安全第一**：台顶天气**突变极快**，遇大风大雨果断下撤
